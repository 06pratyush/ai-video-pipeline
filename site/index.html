AI Video Studio is a free, open-source local AI video generator for Windows, Linux and macOS. Paste a script, pick a style, and eight stages later you have a narrated, scored, subtitled, colour-graded MP4 — rendered entirely on your own GPU. No cloud, no subscription, and nothing ever leaves your machine.

How it works

Eight stages, all running locally

When you press Generate, the backend queues your project and a worker thread walks it through the stages below. Each stage hands its output to the next. Optional stages fail soft — if MusicGen is missing, you get a video without music rather than an error.

  1. 1

    Narration refinement Always

    Your raw script is rewritten into clean spoken narration — contractions, pacing, and the awkward phrasing that reads fine but sounds wrong.

    Gemma 3 / 4B via Ollama · ~10s

  2. 2

    Scene prompt generation Always

    The narration is split into scenes, and each scene gets a visual prompt written for a diffusion model — subject, setting, lighting, camera.

    Gemma 3 / 4B · ~10s

  3. 3

    Voice synthesis Always

    The narration is spoken by one of eight voices. Your own voice can be cloned from a reference clip through XTTS v2.

    Kokoro TTS · ~5s per 100 words

  4. 4

    Video clip generation Always Slowest stage

    Each scene prompt is rendered to a clip on your GPU. The model size is chosen by how much VRAM is actually free — the 14B model when there is room, the 1.3B model when there is not.

    Wan2.1 1.3B / 14B via ComfyUI · ~3 min per scene

  5. 5

    Background music Optional

    A score is composed to match the mood your Skill specifies, then auto-ducked beneath the narration.

    MusicGen Small · ~30s per scene

  6. 6

    Subtitles Optional

    The rendered audio is transcribed back to text with timings, then burned into the picture — which is why Social Short turns this on by default.

    faster-whisper Base · ~10s per minute of audio

  7. 7

    Interpolation & upscaling Optional

    Frames are interpolated to 30 fps and the picture is upscaled to 1080p. RIFE and Real-ESRGAN drop in as replacements when installed.

    FFmpeg minterpolate + super2xbr · +30% / +20% render time

  8. 8

    Colour grade & mux Always

    A colour grade and optional film grain are applied, clips are concatenated, audio is mixed, and the result is written out as final.mp4.

    FFmpeg curves / eq / concat · ~30s

What makes it survivable

  • VRAM-aware routing. The model is picked from free VRAM at the moment the stage runs, so a full GPU downgrades instead of crashing.
  • A persistent queue. Progress lives in SQLite, so closing the app mid-render does not lose the job.
  • A scene cache. Keyed on sha256(prompt + seed + model + resolution) — re-rendering a project only redoes the scenes that changed.
  • Soft failure. Optional stages degrade rather than aborting the render.

Architecture

Three tiers, each replaceable

The desktop app never talks to a model directly. It talks to a local daemon, and the daemon owns the model lifecycle.

Electron frontend

React 18 · Vite · Zustand · Tailwind

Project library, script editor, render panel, live VRAM meter, template and model browsers, batch modal.

REST + WebSocket 127.0.0.1:7860

Python daemon

FastAPI · SQLAlchemy 2.0 · uvicorn

Generation queue, VRAM-aware model lifecycle, scene cache, 11 REST routes and a WebSocket progress stream.

subprocess lazy start

Local runtimes

ComfyUI · Ollama · FFmpeg

Started on demand, and stopped only if this app was the one that started them.

The daemon binds to 127.0.0.1 only and has no authentication, by design — the trust boundary is your machine. See the security policy for the full threat model.

Skills

One preset decides the whole look

A Skill bundles voice, speed, scene pacing, aspect ratio, music mood and the FFmpeg post-processing chain into a single choice. Seven ship by default, and they are plain JSON — copy one to make your own.

First launch takes about 17 minutes

That is a one-time download of roughly 20 GB — PyTorch and CUDA, ComfyUI and its dependencies, the Wan2.1 weights, and the Ollama model. After that you can disconnect permanently.

AMD is not supported yet

Wan2.1 has no ROCm path, so there is no working AMD route today. CPU-only mode runs on any machine but is roughly 10× slower — hours rather than minutes per video.

FAQ

Common questions

Is AI Video Studio free?

Yes. It is MIT licensed and free permanently. There is no account, no metering, no paid tier and no telemetry. The only costs are your electricity and disk space.

Does it work offline?

Yes, after setup. The first launch downloads roughly 20 GB of models and needs a connection. After that every render runs entirely on your machine and you can stay disconnected permanently. The only outbound request the app makes is an optional update check against GitHub Releases.

Do I need an NVIDIA GPU?

For usable speed, yes — 8 GB VRAM minimum, 16 GB or more recommended. CPU-only mode runs but is roughly 10× slower, meaning hours rather than minutes per video. AMD GPUs are not supported because Wan2.1 has no ROCm path.

How long does one video take?

Five to fifteen minutes for a typical 30–60 second video on a 16 GB GPU. Each quality option adds to that: interpolation +30%, upscaling +20%, music about 30s per scene, subtitles about 10s per minute of audio.

How is this different from Runway, Pika or Sora?

Those are hosted services: you submit a prompt, their GPUs render it, and you pay per generation under their content policy. AI Video Studio runs the same class of pipeline on hardware you own — unlimited renders, no upload, no content review, no recurring cost — in exchange for needing a capable GPU and the patience for a local render.

Can I use the output commercially?

The application is MIT licensed, so the code is yours to use. Output rights depend on the models you run — Wan2.1, Gemma, Kokoro, MusicGen and Whisper each carry their own licence. Check each model's terms against your intended use; this project cannot grant rights it does not hold.

Where are my videos stored?

Under app/projects/<project-id>/ beside the application, indexed by a SQLite database. Nothing is uploaded. Note that deleting a project removes its database rows but leaves the media on disk.

Can I add my own voice or visual style?

Yes. Voices clone from a reference clip through XTTS v2. Visual styles are Skills — plain JSON files you can copy and edit. See Skills.
